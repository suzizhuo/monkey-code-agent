## 阶段 2：重写 agent/server.py

### 2.1 隔离命名空间

所有 Isolis 函数用 `isolis_` 前缀，常量用 `ISOLIS_`，避免与 Cage 的 `CAGE_*` 冲突。

### 2.2 七个模块

1. **常量与配置**：从环境变量读 `ISOLIS_*`，预算超 1e6 时打印一次 clamp 通知。
2. **Prompt**：`ISOLIS_SYSTEM_PROMPT` 优先，否则内置（含 profile 说明）。
3. **Token 计数**：优先 tiktoken，失败回退 `len//4`。
4. **LLM**：协议探测（1 token、6 秒）→ Anthropic/OpenAI 客户端。
5. **工具**：5 基线 + 2 开发工具（strict 只有 5）。
6. **记忆**：三轴 —— 轮次、字符、token 压缩。
7. **HTTP**：`/health` `/info` `/history` `/chat`。

### 2.3 协议协商细节

```python
status = probe(base + "/chat/completions", {"max_tokens": 1, ...})
PROTOCOL = "anthropic" if status in (404, 405) else "openai"
```

Anthropic 客户端要去掉尾部 `/v1`：

```python
base = BASE_URL.rstrip("/")
if base.endswith("/v1"):
    base = base[:-3]
```

实测本环境网关是 **anthropic** 协议，这条路径生效了。

### 2.4 工具命名技巧

LangChain 的 `@tool` 用函数名，但我的函数叫 `isolis_run_command`。
方案：自定义装饰器在注册时改名。

```python
def _isolis_named_tool(name):
    def decorator(func):
        if HAS_LANGCHAIN:
            return tool(name)(func)
        wrapped = tool(func)
        wrapped.name = name
        return wrapped
    return decorator
```

### 2.5 记忆压缩算法

```
while tokens(history) + tokens(system) > budget:
    marker = history[0] if history[0] is [compressed history] else None
    body = history[1:] if marker else history
    eligible = len(body) - 2          # 最新一对永不折叠
    if eligible < 2: break
    batch = min(COMPRESS_BATCH, eligible)  # 偶数
    older, rest = body[:batch], body[batch:]
    summary = merge(prior=marker_content, older)
    history = [new_marker] + rest     # 原地覆盖，只有一个 marker
```

## 阶段 3：改造 Dockerfile

### 3.1 与 Cage 版的关键差异

| 项 | Cage 版 | Isolis 版 |
|---|---|---|
| 基础镜像 | `python:3.12-slim-bookworm` | 相同（已 pin） |
| JDK | 无 | `openjdk-17-jdk-headless` |
| Android | 无 | `/opt/android-sdk` 可写 |
| 安装脚本 | 未 COPY | `install-android-sdk.sh` 已 COPY + chmod |
| 用户 | `USER nobody` | 移除（由 `--user` 运行时决定） |
| git 身份 | `Cage Agent` | `Isolis Agent` |

### 3.2 为什么必须移除 `USER nobody`

strict 用 `--user nobody`，tooled 用 `--user 0:0`。如果 Dockerfile 写死
`USER nobody`，tooled 的 apt/pip/npm 会因权限失败。用户身份必须由运行时
`--user` 参数控制。

### 3.3 为什么要 pin `bookworm`

`python:3.12-slim` 浮动 tag 可能指向不含 `openjdk-17` 的发行版。
pin 到 `bookworm` 才有 `openjdk-17-jdk-headless`。

验证：

```bash

docker run --rm test-image java -version
docker run --rm test-image node -v
```

## 阶段 4：宿主机侧小修

### 4.1 state 规范化

原实现直接信任 state 里的字段。现在逐字段校验、补默认值、丢弃非法：

```python
record["container"] = container or "isolis-" + name
record["port"] = port if isinstance(port, int) else None
current = data.get("current")
if not isinstance(current, str) or current not in clean:
    current = None
```

好处：手工编辑 state 或旧版本遗留数据不会让后续命令崩溃。

### 4.2 镜像 tag 用解析后路径

原来哈希的是 source 字符串，`local` 和 `./agent` 会得到不同 tag。
改成哈希 `os.path.abspath(source_dir(...))`，同一目录恒定同 tag。

### 4.3 非快进 pull 降级

原实现 pull 失败直接抛错。现在打印 notice 保留本地 clone，
符合规格「non-ff reported, keep local」。

### 4.4 转发 ISOLIS_MODEL

`ISOLIS_MODEL` 优先级高于 `MCAI_LLM_MODEL`，必须显式传进容器，
否则容器里的优先级链断了。

```
isolis> init
llm: monkeycode-basic/deepseek-flash via mc-direct (key ok len 36 prefix d23...)
```

### 6.2 处理

```bash
DEBIAN_FRONTEND=noninteractive apt-get install -y docker.io
```

安装后 `docker` 20.10.24 + `dockerd` 就位。但 `policy-rc.d` 阻止了服务自启。

### 6.3 配置镜像源

Docker Hub 在本环境不可达。探测后写入：

```json
{"registry-mirrors": ["https://docker.m.daocloud.io"]}
```

### 6.4 启动 daemon

```bash
dockerd --host=unix:///var/run/docker.sock \
        --storage-driver=overlay2 \
        --iptables=true
```

用后台终端管理，不用 `&`。等待 `docker info` 返回版本，约 2 秒。

### 6.5 创建网络

```bash
docker network create \
  --opt com.docker.network.bridge.enable_icc=false \
  isolis-net
```
