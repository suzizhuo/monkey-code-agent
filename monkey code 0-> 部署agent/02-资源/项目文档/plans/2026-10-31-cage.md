# cage Implementation Plan

> **For agentic workers:** one Task per round with a human gate between rounds (workflow and prompts live with the operator, NOT in this repo — see `HANDOFF.md`). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 复刻 Isolis 的「从 0 部署 Agent」能力为自用的 `cage`：宿主机 TUI（11 命令面不变 + `serve`）在 Docker 不可用时自动降级进程模式，容器内 LangChain Agent 运行时带协议协商、工具循环与三维记忆压缩，模型只经 `MCAI_LLM_*` 平台注入。

**Architecture:** 宿主机层只依赖 Python 标准库 + `docker` CLI（或子进程），拆成 `state/naming/runtime/model/httpapi/cli` 六个聚焦模块 + 薄入口 `cage.py`；容器内 `agent/server.py` 从先例移植并按设计文档第 6 条裁剪。所有"能纯化的逻辑"（参数拼装、名字/端口/tag 计算、记忆压缩决策、协议与模型选择）抽成纯函数，测试不需要 Docker 和网络。

**Tech Stack:** Python 3.12+（宿主仅标准库）；容器内 `langchain-core` / `langchain-openai` / `langchain-anthropic` / `playwright`（均 `<1.0.0` 上界，`agent/requirements.txt`）；测试 `pytest 9.1.1`（本机在位）。

**Spec:** `specs/2026-10-31-cage-design.md`（含 §13 Builder 检查的 11 条裁定与 §14-§19 能力扩展契约，全部对本计划有效）

## Global Constraints

- 模型只经 `MCAI_LLM_BASE_URL` / `MCAI_LLM_API_KEY` / `MCAI_LLM_MODEL` 注入；缺失即一行报错。任何日志/输出只报 key 长度 + 前 3 位，绝不落盘、绝不进 state。
- 不写死任何平台/厂商知识：无平台前缀常量、无内置模型常量；黑名单默认空，`CAGE_BLOCKED_MODELS` 逗号分隔可配。
- TUI 11 命令（`setup/doctor/init/chat/use/status/rebuild/stop/profiles/help`）名字、选项、语义与先例一致；新增命令仅四个：`serve`、`work`、`key`、`publish`（§14-§21 追加，全部为加法、不改旧语义）。环境前缀 `ISOLIS_*` → `CAGE_*`（`MCAI_LLM_*` 不动）。
- 常量（先例值，逐字保留）：`MAX_TURNS=400` `MAX_TOOL_STEPS=8` `SHELL_TIMEOUT=120` `INSTALL_TIMEOUT=1800` `MAX_OUTPUT=20000` `CONTEXT_TOKENS=900000` `CONTEXT_HARD_LIMIT=1000000` `MAX_MESSAGE_CHARS=900000` `ARCHIVE_MAX=4000`；端口池 `18080-18119`，容器内 8080，`serve` 固定 18079。**v2（spec §20）**：`CAGE_SUMMARIZE=0`（LLM 摘要默认关）、`CAGE_INDEX_MAX_CHARS=20000`——`CONTEXT_TOKENS` 超限的动作从"LLM 摘要"改为"原文淘汰+确定性索引"，`COMPRESS_BATCH/SUMMARY_*` 仅 `CAGE_SUMMARIZE=1` 时生效。
- 隔离红线（先例 §4）：`--cap-drop ALL` + profile 白名单；tooled 恰好 6 cap（CHOWN,DAC_OVERRIDE,FOWNER,SETUID,SETGID,SETFCAP）；strict 只读根 + nobody + 无 cap；无宿主机挂载、无 docker.sock、无 `--privileged`/`SYS_ADMIN`；单端口仅绑 127.0.0.1；tmpfs `/tmp /work /dev/shm`；`no-new-privileges`。
- 输出 ASCII 风格（先例 §12）：一行一事实，失败指明下一步；中文内容经 `safe_text`（surrogateescape + gb18030 兜底）。
- state 家目录 `~/.cage/`（`CAGE_HOME` 可覆盖）；写文件必须 tmp + flush + fsync + `os.replace`；并发用 `fcntl.flock` 排他锁。
- 进程模式一律绑 `127.0.0.1`；probe 探测失败不静默改 state，仅在重建时写入（裁定 #5）。
- 提交仅作本地记录、不 push；operator 说跳过则不提交。
- **能力扩展常量（§14-§20，逐字保留）**：`CAGE_AUTONOMY`（manual/assisted/auto，默认 auto）；`CAGE_ACTION_BUDGET`（500 次/agent/天，超额降档 assisted）；`CAGE_WATCHDOG_SECS`（0=关）；`CAGE_CHALLENGE_HOSTS`（默认空=只探测不破解）；`CAGE_SOLVER_CMD`（外部 solver 钩子）；`CAGE_URL_POLICY`（默认 `all`，可 `allowlist:a.com,b.com`）；`CAGE_WORKER_CONCURRENCY`（3）；`CAGE_WORKER_MAX_TURNS`（40）；`CAGE_PROCESS_INSTALL`（默认 0=进程模式禁装）；`CAGE_PROCESS_NICE`（10）；`CAGE_AGENT_MODE`（默认 `orchestrator`，`bare` 仅调试）；`CAGE_GH_TOKEN`（PAT，回显只报长度+前缀）、`CAGE_SSH_KEY_B64`（base64 私钥，env 注入）、`CAGE_PUBLISH_REPO`（默认空=拒绝发布）、`CAGE_GH_CREATE_REPO`（默认 0，本期预留不实现）；`CAGE_RISK_LEVEL`（strict/balanced/aggressive，**默认 aggressive**，operator 选定）、`CAGE_SEARCH_CMD`（搜索 API 钩子）；`CAGE_SKILLS_REPO`（默认 `https://github.com/suzizhuo/suzizhuo-skill-repository`）、`CAGE_SKILLS_REFRESH_HOURS`（24）、`CAGE_SKILLS_SCAN`（1，`init --no-scan` 可跳）。`init/setup/rebuild` 增 `--risk`。**代理池/分布式规避封禁明确不实现**。
- 主代理**默认即 orchestrator**（`init` 即激活，无需 env；`CAGE_AGENT_MODE=bare` 仅调试）：工具集恒为 `delegate` + `challenge_probe` + `solve_challenge`；文件/命令/浏览/安装能力只在 worker 内；worker 深度 1、不可再派发。主代理超限只做原文淘汰+确定性索引（零模型调用），LLM 摘要仅 `CAGE_SUMMARIZE=1` 应急。
- 审计：每次工具调用一条 JSONL（容器 stdout → 宿主 `~/.cage/logs/audit-<agent>.jsonl`）；敏感参数只留 sha256 前 8 位。
- 人机验证破解只对 `CAGE_CHALLENGE_HOSTS` 命中的 host 生效（默认空=探测并升级给人）；基线 solver 为本地 OCR（agent 自装 tesseract/pytesseract），不预置商业打码服务。

## Review Focus

- **`agent/server.py` 的工具集随 profile 变化**：tooled 6 个、strict 5 个，`/info` 的 `tools[]` 与 `install` 字段必须一致（删 Android 后的新基线是 6/5，不是先例的 7/6）。
- **`/info` 契约**：不得再出现 `android_home`；必须含 `via=mc-direct`、`injected`、`protocol`、记忆六元组。
- **进程模式的 `stop`/`rebuild` 可杀性**：子进程必须 `start_new_session` + 进程组可杀，日志落 `~/.cage/logs/<name>.log`（裁定 #2）。
- **`serve` 与 TUI 共存**：所有 state 变更走 flock；`allocate_port` 排除 18079（裁定 #1、#7）。
- **模型选择链退化**：`CAGE_MODEL` > `MCAI_LLM_MODEL` > 目录首个非黑名单 id > `CAGE_DEFAULT_MODEL` > 一行报错；无前缀档、无内置常量（裁定 #8、设计 §8）。
- **`CAGE_BASE_IMAGE` 进镜像 tag**，否则换基础镜像会静默复用旧镜像（裁定 #11）。
- 先例已知缺口（文档化、本期不修）：OpenAI 协议路径不绑定工具。README「已知限制」明写。
